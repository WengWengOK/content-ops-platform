# 突发热点分析指南

本文档解释 ContentOps 突发热点检测的判定口径与使用建议，供 AI Agent 做选题与热点分析时参考。

## 判定口径

每次轮询（默认 30 分钟）会把最新热榜与上一快照做「同平台 + 同标题」对比：

| 标记 | 判定条件 | 含义 |
|------|----------|------|
| 🆕 新上榜 | 该主题此前从未出现 | 全新话题，首发红利最高 |
| 🔥 飙升 | 热度环比涨幅 ≥ 50%（阈值可配） | 热度快速攀升，借势窗口期 |
| ↑ 上升 | 涨幅 ≥ 20% 或排名上升 ≥ 5 位 | 温和走强，适合跟进 |
| （无标记） | 热度平稳或回落 | 常规话题 |

爆发事件会**落库**（`GET /trends/bursts`），即使下一轮快照热度回落，历史爆发依然可查。

## 使用建议

### 选题策略

1. **新上榜**：抢首发。内容稀缺、竞争小，适合快速产出“第一视角”内容
2. **飙升**：借势。热度正在放大，适合在 1-2 小时内完成产出
3. **上升**：跟进。还有红利但竞争开始，需要差异化角度
4. 无标记但 `analysis.relevance` 高：长期话题，适合系列化内容

### 风险识别

- `analysis.riskFlag=true`：疑似谣言/标题党/夸大，选题前先核实来源
- `analysis.credibility < 60`：可信度偏低，避免直接引用未经证实的细节
- 跨平台对比时优先引用可信度高的平台（如知乎问题原文、官方新闻）

### 时间窗口

- `timeRange=1h`：捕捉当下热点，适合“追热点”
- `timeRange=24h`：当日热点盘点，适合日报/选题会
- `timeRange=7d`：趋势判断，适合周报与内容排期
- `GET /trends/history` 可看单主题 24h 热度曲线与上榜时长，判断话题生命周期

## 阈值配置

默认阈值可通过环境变量调整：

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `CONTENTOPS_TREND_BURST_HEAT_RATIO` | 0.5 | 飙升：热度环比涨幅 |
| `CONTENTOPS_TREND_BURST_HEAT_RISE` | 0.2 | 上升：热度环比涨幅 |
| `CONTENTOPS_TREND_BURST_RANK_RISE` | 5 | 上升：排名上升位数 |
